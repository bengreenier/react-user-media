# Examples

Vite + React example app for `@bengreenier/react-user-media`.

Requires **Node.js 22.12+** and React 19 (workspace packages).

```bash
pnpm --filter examples dev
pnpm --filter examples build
```

Linting and formatting are handled by Biome at the monorepo root (`pnpm lint` / `pnpm format`).
